# 🎬 Studio Ghibli Movies App

Aplicativo mobile desenvolvido com **React Native e Expo** para a disciplina de Coding. O projeto consome dados de uma API externa para apresentar nomes de filmes produzidos pelo Studio Ghibli.

## 📌 Sobre o projeto

O objetivo desta atividade é desenvolver uma aplicação mobile utilizando React Native com Expo, realizando a integração com uma API para buscar, processar e exibir informações na tela, aprimorando os conhecimentos sobre o React Native.

O aplicativo apresenta um catálogo de filmes do **Studio Ghibli**, permitindo visualizar informações sobre as produções do estúdio de animação japonês.

## 🚀 Tecnologias utilizadas

- **React Native:** desenvolvimento da interface mobile.
- **Expo:** ambiente e ferramentas para desenvolvimento e execução do aplicativo.
- **JavaScript:** linguagem utilizada no desenvolvimento.
- **API REST:** integração para obtenção dos dados dos filmes.

## 🔌 API utilizada

O projeto utiliza a [Studio Ghibli API](https://ghibliapi.dev/films/), que disponibiliza informações sobre os filmes do estúdio.

## ⚙️ Funcionalidades

- Listagem de filmes do Studio Ghibli.
- Consumo de dados de uma API externa.
- Exibição das informações recebidas da API.
- Interface desenvolvida para dispositivos móveis.

## 📥 Como executar o projeto

### Pré-requisitos

- Node.js instalado.
- npm instalado.
- Expo Go instalado no celular ou emulador configurado.

### Instalação

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Acesse a pasta do projeto:

```bash
cd NOME_DO_PROJETO
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o Expo:

```bash
npx expo start
```

5. Utilize o aplicativo Expo Go para escanear o QR Code e executar o projeto no celular.

## 🎓 Objetivo acadêmico

Esta atividade tem como finalidade aplicar conhecimentos de desenvolvimento mobile com React Native e Expo, além de praticar o consumo de APIs, manipulação de dados externos e construção de interfaces dinâmicas.
